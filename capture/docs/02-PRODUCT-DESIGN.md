# Capture — 产品设计 (02)

## 1. 设计原则

1. **对话优先（Conversation-first）**：创作的主要界面是聊天；面板是可视化视图与精细编辑工具。
2. **结构优先于散文（Structure > prose）**：每个产物（章节、镜头）都是结构化数据 + 渲染文本；智能体与人共同维护。
3. **以资产为中心的一致性（Asset centric consistency）**：文本、镜头、生成结果都关联资产；维护身份一致性是第一优先级。
4. **渐进式保真（Gradual fidelity）**：文本 → 镜头 → 静帧 → 片段 → 预告片，每层可跳过/回退。
5. **处处可追溯（Provenance everywhere）**：展示“由镜头 X 使用资产 Y v2 生成”。
6. **生成不阻塞（No blocking generation）**：长任务进入作业面板；UI 保持响应。
7. **两种主题下可读**：仅使用浅/深主题 token。
8. **键盘与焦点**：遵循基本 DSH 模式。
9. **右侧Capture工作室页面常驻**：Capture 工作室作为右侧侧边栏工作区页面（`rightbar`），随 DSH 窗口缩放，中间对话框保持可见，用户可在对话进行时并行查看/编辑 Capture 产物。

## 2. 信息架构 (IA)

```text
Session (DSH)
└─ (optional bound ProjectId)        # 可选绑定 ProjectId
Project (global plugin storage)      # 项目（全局插件存储）
├─ Chapters
│   └─ Scenes (optional)
│       └─ Shots (shot list / versioned)
├─ Assets
│   ├─ Characters
│   ├─ Props
│   ├─ Locations
│   └─ Style Packs
├─ Generations (images/videos)       # 生成（图像/视频）
├─ Trailers
└─ Branches (forks)                  # 分支（分叉）
```

### 客户端 UI 界面（DSH 槽位）

| 槽位 | 用途 | 说明 |
|---|---|---|
| `sidebar.panellist` | 左侧全局导航入口（Capture 插件入口） | 图标 "Capture"，点击打开/关闭右侧 Capture工作室页面 |
| `rightbar` / `sidebar.right.pane.tab` | 右侧侧边栏工作区页面 | 右侧侧边栏打开 Capture 工作室页面，随 DSH 窗口缩放，中间对话框保持可见 |
| `conversation.composer.dock` | 底部徽章 | 显示 "Capture N project(s)"，轻量状态入口 |
| `settings.general.item` | 设置区 | Capture 提供商/配置页面（阶段 2+） |
| `conversation.input.dock` | 可选快捷操作栏 | 项目绑定时显示快捷操作（例如“生成镜头图”） |
| `rightbar`（对话框） | 生成进度/差异/预览 | 生成进度、分支差异、预告片预览、导出对话框 |

决策：**项目绑定存在于会话中**。打开会话 → 如果绑定了项目，Capture工作室面板可直接打开该项目。如果未绑定项目，Capture工作室面板在轻量状态下提供“创建/打开项目”。

## 3. 主要用户旅程 (Journeys)

### J1 创建新作品（MVP，Capture工作室面板内完成）

```text
用户点击左侧 "Capture" 图标 → Capture工作室面板打开（默认“项目”标签）
用户点击“新建项目” → 弹出对话框：项目名、类型、一句话梗概
提交后 → Capture工作室左侧区项目列表新增一行，自动选中该项目
Capture工作室右侧故事板显示该项目的故事板（默认第 1 章）
```

### J2 编辑章节与分镜脚本（故事板主工作区）

```text
Capture工作室面板顶部章节切换器选择“第 1 章”
Capture工作室右侧故事板显示：第 1 章标题 + 故事大纲 + 分镜脚本表格
用户点击某个镜头行 → 行高亮，可进行行内编辑
用户修改对白/镜头语言/资产绑定 → 立即保存，支持撤销
```

### J3 生成角色图（资产库）

```text
用户点击左侧 "Capture" 图标 → Capture工作室面板打开（默认“项目”标签）
用户点击顶部“资产”标签 → Capture工作室左侧区切换为资产模式
用户点击上方横向 tab 切换“角色”
Capture工作室右侧故事板显示角色网格卡片列表
用户点击“新建角色” → 弹出对话框：名称、描述
提交后 → 网格新增一张空卡片
```

### J4 一致性检查

```text
用户点击“一致性检查” → Consistency Agent 扫描镜头+资产；列出警告（只读）
UI：每个镜头行显示警告徽章，Capture工作室面板底部显示建议条
```

### J5 分支/合并

```text
用户：“fork 第4章尝试新结局”
  → 深拷贝项目分支。
  … 工作 …
用户：“合并回主线”
  → 差异视图（章节 + 镜头）→ 选择变更块 → 应用。
```

│ 对话内容...                                     │ │ ┌──────────────┐ ┌──────────────────────┐ │
│                                                 │ │ │ Capture工作室│ │ Capture工作室右侧故事板 │ │
│                                                 │ │ │ 左侧区     │ │                          │ │
│                                                 │ │ │ ┌─────────┐ │ │ 章节大纲 / 剧情摘要    │ │

中间对话框保持可见，右侧侧边栏随 DSH 窗口缩放，为 10 列分镜脚本表格和资产详情提供足够空间。

### 4.1 Capture工作室页面顶部栏

从左到右：
- **联动开关**（默认关闭，位于章节切换器左侧）：打开后，对话框讨论中的镜头/章节会自动高亮并跳转到对应行；智能体提议的编辑在对应行显示“待审核”徽章。
- **章节切换器**（下拉选择器）：显示当前章节名，章节多时可滚动。
- **标签页切换**：“项目” / “资产”。

### 4.2 Capture工作室左侧区（面板左列，约 160-180px）

**项目模式下方内容**：
- 项目列表，每行显示：项目名、类型、一句话梗概、创建时间、最后修改时间。
- 无搜索/过滤（MVP）。
- 点击具体项目 → Capture工作室右侧故事板替换显示该项目的故事板。
- 底部“新建项目”按钮，点击弹出对话框（项目名、类型、一句话梗概）。

**资产模式下方内容**：
- 上方横向 Tab 栏：“角色” / “场景” / “物品”，默认“角色”。
- 下方网格卡片资产列表（一行显示多个卡片，根据宽度自适应 2-3 列）。
- 每张卡片显示：缩略图占位、名称、类型徽章、版本。
- 底部“新建资产”按钮，点击弹出对话框（名称、描述）。

### 4.3 Capture工作室右侧故事板（面板右列，常驻显示）

**顶部栏**：
- **联动开关**（默认关闭，位于章节切换器左侧）：打开后，对话框讨论中的镜头/章节会自动高亮并跳转到对应行；智能体提议的编辑在对应行显示“待审核”徽章。
- **章节切换器**（下拉选择器，显示当前章节名，章节多时可滚动）。
- **标签页切换**：“项目” / “资产”。
- 当前未选中项目时显示“请先选择项目”。

**主体内容（根据左侧标签切换显示，从上到下，支持上下和左右滑动）**：
- **当左侧选择“项目”标签时**：Capture工作室右侧故事板显示该项目的故事板，分三部分：
  - **第一部分：故事大纲 / 剧情摘要**
    - 当前章节的标题 + 一句话梗概 + 关键节拍列表。
  - **第二部分：世界观与人物设定**
    - 当前项目的资产设定摘要（角色、场景、物品、风格包），用于资产绑定和一致性检查参考。
  - **第三部分：分镜脚本表格（核心，支持横向滑动）**
    - 表格列：编号、时长（秒）、景别+角度、运镜、画面描述（提示词）、出场角色与动作、台词/旁白、音效/音乐、资产绑定、状态徽章。
    - 每行是一个镜头，支持点击选中（行高亮，可进行行内编辑）。
    - 支持拖拽重排镜头顺序（MVP 可先简化为手动排序索引）。
    - 状态徽章：排队（灰色）/ 运行中（强调色旋转指示）/ 完成（成功）/ 失败（危险）/ 已取消（弱化）。
    - “待审核”徽章：智能体提议的编辑在对应行显示。
- **当左侧选择“资产”标签时**：Capture工作室右侧故事板显示资产网格卡片列表（由上方横向 Tab 切换“角色”/“场景”/“物品”控制显示哪一类资产）。

**底部**：
- 智能体建议条（可折叠，显示差优先编辑建议，点击查看 diff 并接受/拒绝）。

### 4.4 资产详情（弹出对话框）

- 点击资产卡片后弹出对话框。
- 字段：名称、描述、参考图（上传/重排/删除）、特征表单（取决于类型）、身份锁定提示词（可编辑）、“重新生成锁定”按钮、使用列表（跳转到引用该资产的镜头）、版本历史。

## 5. 交互模式 (Interaction patterns)

- **差异优先编辑（Diff-first edits）**：智能体绝不静默覆盖；提议的变更（创建/更新/删除）以差异形式展示，并提供接受/拒绝/修改。
- **快捷标签（Quick chips）**：智能体输出 1—3 个可操作标签；用户点击。
- **行内编辑（Inline edit）**：任何产物字段可编辑；立即保存并支持撤销。
- **空状态（Empty states）**：每个面板都有可操作的空白状态。
- **渐进式披露（Progressive disclosure）**：高级字段（镜头焦距、转场时长）放在“高级”折叠区。
- **错误（Error）**：本地化；生成失败显示重试 + 日志。
- **面板开关**：点击左侧 `sidebar.panellist` 的 "Capture" 图标，右侧侧边栏 Capture工作室页面打开/关闭；中间对话框保持可见，仅被右侧侧边栏压缩宽度。

## 6. 导航与状态

- 项目/章节/镜头状态全局存储（插件存储）；UI 通过选择器读取。会话绑定指针按会话存储（更倾向全局最后打开）。
- 当会话没有项目时，Capture工作室面板 = 项目选择器 + 创建。
- 通过命令深链：`/story open <projectId>`。

## 7. 响应式与主题

- 仅使用 DSH token（`--dsw-alias-*`）；除艺术作品外不使用字面颜色。
- Capture工作室页面随 DSH 窗口缩放，内部滚动；外部布局由 DSH shell 负责（对话区域自动压缩）。
- 深/浅色并排测试（按 verification.md）。

## 8. 可访问性

- 为列表/按钮/对话框设置 ARIA 角色。
- 键盘：Escape 关闭覆盖层；Tab 导航；标签可聚焦。
- 减少动态效果：遵循 DSH 的减少动态效果设置。

## 9. UX 决策：右侧侧边栏 vs 主面板替换

DSH 主视图是会话驱动（每个会话对应对话）。选项：

- A. 注册 `main` 槽位替换：激活时显示工作室，否则显示对话（风险：与宿主 `main` 冲突，且中间对话框会被切走）。
- B. 右侧侧边栏工作区页面（`rightbar` / `sidebar.right.pane.tab`）：点击左侧 "Capture" 图标，在右侧侧边栏打开 Capture工作室页面，中间对话框保持可见，侧边栏随窗口缩放（v1 推荐）。
- C. 仅设置页（不够）。

**决议（阶段 1 MVP）**：工作室页面使用右侧侧边栏工作区页面（`rightbar`），通过 `sidebar.panellist` 左侧图标入口开关。面板内左侧Capture工作室左侧区 + 右侧Capture工作室右侧故事板，切换项目/资产直接替换显示。
