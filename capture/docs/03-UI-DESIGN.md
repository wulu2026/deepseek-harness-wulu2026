# Capture — UI 设计 (03)

## 1. 设计哲学

- **宿主外观**：与 DSH 设置/插件管理器一致：卡片式列表、圆角 8px、token 配色。
- **媒体优先**：镜头/资产卡片突出显示缩略图；文本为次要信息。
- **密度**：中等；信息丰富但不杂乱。
- **通过徽章展示状态**：生成状态、一致性警告、资产使用情况。
- **右侧Capture工作室页面常驻**：右侧侧边栏工作区页面，随 DSH 窗口缩放，不遮挡左侧全局导航。

## 2. 整体布局（右侧侧边栏工作区页面，随窗口缩放）

```
┌ 中间对话框（conversation） ─────────────────────┐ ┌ 右侧侧边栏（rightbar，Capture工作室）─┐
│ [联动开关] [章节：第 1 章 ▼] [项目] [资产]│ │                                             │
│ 对话内容...                                     │ │ ┌──────────────┐ ┌──────────────────────┐ │
│                                                 │ │ │ Capture工作室│ │ Capture工作室右侧故事板 │ │
│                                                 │ │ │ 左侧区     │ │                          │ │
│                                                 │ │ │ ┌─────────┐ │ │ 章节大纲 / 剧情摘要    │ │
│                                                 │ │ │ │ 项目A   │ │ │ ┌─────────────────┐   │ │
│                                                 │ │ │ │ 项目B   │ │ │ │ 分镜脚本表格    │   │ │
│                                                 │ │ │ │ [+ 新建]│ │ │ │ • Shot 1 [状态] │   │ │
│                                                 │ │ │ └─────────┘ │ │ │ • Shot 2 [状态] │   │ │
│                                                 │ │ │ ┌─────────┐ │ │ │ ...             │   │ │
│                                                 │ │ │ │ 资产列表│ │ │ └─────────────────┘   │ │
│                                                 │ │ │ │ [角色]  │ │ │ 表格行选中后可行内编辑│ │
│                                                 │ │ │ │ [场景]  │ │ │ ┌─────────────────┐   │ │
```

- 中间对话框保持可见，右侧侧边栏随 DSH 窗口缩放。
- Capture工作室左侧区宽度约 160-180px；Capture工作室右侧故事板占剩余宽度。
- Capture工作室右侧故事板常驻显示，切换项目/资产直接替换显示。
- 面板关闭时左侧全局导航（插件、自动化任务等）完全可见，不被遮挡。

## 3. 颜色 token

仅使用 DSH 主题 token：

- `--dsw-alias-bg-layer-default`（面板背景）
- `--dsw-alias-bg-layer-raised`（卡片）
- `--dsw-alias-fg-default`、`--dsw-alias-fg-muted`
- `--dsw-alias-stroke-default`
- `--dsw-alias-accent-default`
- `--dsw-alias-warning-default`、`--dsw-alias-danger-default`、`--dsw-alias-success-default`

艺术作品（图标/缩略图）可使用字面颜色。

## 4. 排版

- H1 18px/24；H2 16/22；正文 14/20；说明文字 12/16。
- 字体：继承 DSH。

## 5. 组件（MVP 规格）

### 5.1 Capture工作室面板顶部栏

从左到右：
- **联动开关**（切换按钮，默认关闭）：打开后，对话框讨论中的镜头/章节自动高亮并跳转到对应行；智能体提议的编辑在对应行显示“待审核”徽章。
- **章节切换器**已移至 Capture工作室右侧故事板顶部（见 §5.5）。
- **项目/资产切换**位于左侧区域上方，切换后左侧区下方内容随之替换（项目列表 / 资源网格卡片列表）。

### 5.2 项目列表行（Capture工作室左侧区）

- 每行显示：项目名（加粗）+ 类型标签 + 一句话梗概（1 行，溢出省略）+ 创建时间 + 最后修改时间。
- 悬停高亮；选中后背景加深。
- 底部“新建项目”按钮（文本按钮或图标+文字）。

### 5.3 资产网格卡片（Capture工作室左侧区，资产模式）

- 每张卡片：方形缩略图占位（16:9 或 1:1，无内容时用类型图标）+ 名称（1-2 行）+ 类型徽章 + 版本。
- 卡片间距 8px；一行根据面板宽度自动显示 2-3 张。
- 点击卡片弹出资产详情对话框。
- 底部“新建资产”按钮。

### 5.4 资产详情对话框（弹出）

- 字段：名称（文本输入）、描述（文本域）、参考图（上传/重排/删除，缩略图列表）、特征表单（取决于类型）、身份锁定提示词（可编辑，“重新生成锁定”按钮）、使用列表（跳转到引用该资产的镜头）、版本历史。
- 底部：取消 / 保存。

### 5.5 章节切换器（Capture工作室右侧故事板顶部）

- 下拉选择器，显示当前章节名。
- 章节数量多时支持横向滚动。

### 5.6 故事大纲 / 剧情摘要（Capture工作室右侧故事板第一部分）

- 章节标题 + 一句话梗概 + 关键节拍列表。
- 可折叠。

### 5.7 世界观与人物设定（Capture工作室右侧故事板第二部分）

- 当前项目的资产设定摘要（角色、场景、物品、风格包），用于资产绑定和一致性检查参考。
- 可折叠。

### 5.8 分镜脚本表格（Capture工作室右侧故事板核心，支持横向滑动）

- 表格列：编号、时长（秒）、景别+角度、运镜、画面描述（提示词）、出场角色与动作、台词/旁白、音效/音乐、资产绑定、状态徽章。
- 每行是一个镜头，支持点击选中（行高亮，可进行行内编辑）。
- 支持拖拽重排镜头顺序（MVP 可先简化为手动排序索引）。
- 状态徽章：排队（灰色）/ 运行中（强调色旋转指示）/ 完成（成功）/ 失败（危险）/ 已取消（弱化）。
- “待审核”徽章：智能体提议的编辑在对应行显示。

### 5.9 资产卡片（资产网格）

- 缩略图区域（方形，无内容时用类型图标占位）。
- 名称（1-2 行，溢出省略）。
- 类型徽章（角色/场景/物品）。
- 版本小字。
- 悬停：显示编辑/删除图标。

### 5.10 GenerationJobRow（生成作业行，阶段 2+）

- 类型图标 + 来源标签 + 进度条 + 取消/重试。
- 输出预览缩略图。

### 5.11 TrailerTimeline（预告片时间线，阶段 3+）

- 节拍的水平标签及持续时间；总时长。
- 风格选择器；标题卡编辑器。
- 预览播放器（原生 `<video>`）。
- 导出按钮。

### 5.12 空状态

- 项目列表空：“尚无项目——点击‘新建项目’创建”。
- 资产列表空：“尚无资产——点击‘新建资产’创建”。
- 镜头列表空：“本章暂无镜头——点击智能体建议或手动添加”。
- 所有列表遵循 DSH 空状态样式（图标 + 文本 + 主要操作）。

### 5.13 状态/徽章

- 生成排队（灰色）/ 运行中（强调色旋转指示）/ 完成（成功）/ 失败（危险）/ 已取消（弱化）。
- 一致性警告（警告点 + 工具提示）。
- 资产复用次数。
- “待审核”徽章：智能体提议的编辑在对应行显示。

## 6. 图标与资源

- 为插件提供原创简单 SVG 图标（复用？新设计；不得复制品牌图标）。在包根目录提供 `icon.svg`。
- 镜头类型图标：最小 SVG 集（自定义，不依赖第三方）。
- 除非作为生成媒体，否则不使用位图。

## 7. 本地化

- 使用区域设置 JSON（`locale/en.json`、`locale/zh.json`）存放所有 UI 文本，包括元标题/描述。
- 使用 DSH `ctx.locale` 服务（客户端）。

## 8. 动效

- 列表出现时使用 DSH AnimatedRows。
- 不自定义布局观察器。
- 遵循减少动态效果。

## 9. 验证

- 浅/深色截图并排（浏览器控制可用时）。
- 除艺术作品外不使用字面颜色。
- 检查槽位渲染不崩溃。
- 右侧侧边栏随 DSH 窗口缩放，左右两列内容不挤压、不溢出。
- 分镜脚本表格支持横向滑动，所有列可见。
