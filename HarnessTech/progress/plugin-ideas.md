# Plugin Ideas —— 插件想法池

> 定位：攒插件灵感的地方。原则：**想法从能力缝的缺口来**，而不是凭空想「做什么 app」。

## 怎么从能力缝里找想法

一个能力缝 = Definition（接口）+ Provider（实现）+ Consumer（消费者）。找 niche 就沿着这三个角色问：

1. **Provider 缺口**：官方 Definition 在、但某类 Provider 只有官方实现、外部能补——例如某个模型适配器、某个 web search provider、某个 MCP 连接器、某个 shell 执行后端；
2. **Consumer 缺口**：官方有服务、但缺一个「把它用在某个业务场景」的消费者——例如用 `ctx.fs` / `ctx.storage` 接你的内部系统；
3. **信任边界缺口**：需要「最小权限」的专用工具——一个只干一件事、权限收窄的工具比通用 `bash` 更安全也更受欢迎；
4. **官方 showcase 没覆盖的场景**：项目自述「官方包不比社区包更重要」，任何让你兴奋的插件都成立。
