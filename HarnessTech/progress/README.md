# progress —— 轨迹层

> 定位：跟踪「从外部研究者 → 生态重要成员」这条路上的里程碑与证据。它不解释项目本身（那是 atlas 与 ecosystem 的事），只记录你走了多远、拿出了什么。

## 三个文件

- `roadmap.md` —— 里程碑与验收标准（按真实产出排，不按「读完某份源码」排）；
- `contribution-log.md` —— 带日期的贡献账本（做了什么、发到哪、结果）；
- `plugin-ideas.md` —— 插件想法池（从能力缝里找 niche 的方法 + 候选表）。

## 怎么用

1. 开工前看 `roadmap.md`，确认当前里程碑；
2. 每完成一件对外可见的事，就在 `contribution-log.md` 加一行；
3. 有插件灵感就丢进 `plugin-ideas.md`，攒够了回来挑。

## 与其它层的关系

- 「怎么走」的方法在 `ecosystem/`；「走得怎么样」的证据在这里；
- 「为什么这么走」的复盘在 `methodology/`。


*基于 dsh 0.2.2-alpha.2（2026-10-29）*
